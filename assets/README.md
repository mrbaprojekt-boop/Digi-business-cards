# assets/

Drop the official CDR logo here and it is used on every card, unchanged.

- **Preferred:** `logo.svg` — sharp at any size, tiny file.
- Also accepted: `logo.png`, `logo.webp`, `logo.jpg`.

The file must be **only the black "CDR" wordmark** (transparent or lime background) —
the card already places it inside a lime block, so a transparent PNG/SVG of just the
black letters works best. A solid lime square also works.

After adding or replacing the file, run `node build.mjs` (or double-click
`Rebuild and open.bat`).

If no file is here, the card falls back to "CDR" set in a heavy sans-serif.
